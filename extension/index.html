        Sketch control rules
        
Use top-level const number, boolean or quoted-string literals. Expressions and nested declarations stay in code.

        
A comment directly above (no blank line) or on the same line supplies the label; otherwise the identifier becomes a readable label.

        
// Speed @range 0 5 0.1
const SPEED = 1;

        
@range <min> <max> <step> adds a slider: use finite bounds, min < max and step > 0. Without it, numbers get number fields.

        
Booleans get switches; strings get text boxes, except #rgb/#rrggbb colors get color pickers. Edits update the source, preview and saved sketch.
